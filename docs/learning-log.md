# 학습 로그

만들면서 마주친 문제와 그 해결 과정을 기록합니다.
발행한 블로그 글은 링크로 연결하고, 발행 전에는 **글감 상태**로 둡니다.

기록 형식은 아래를 따릅니다.

> 상황(무엇을 만들다가) → 증상(로그·쿼리 수·응답 시간) → 가설 → 검증 → 해결 → 남은 의문

**숫자가 없는 항목은 아직 글이 아닙니다.** 쿼리 21개 → 2개, 840ms → 47ms 같은 값이 들어가야 기록의 의미가 생깁니다.
